# Customer Analytics and Shipping Performance Dashboard

## Project Overview

This project focuses on analysing customer, product, shipping and warehouse data to generate meaningful business insights. The project uses Microsoft Excel for data cleaning and preparation and Microsoft Power BI for data analysis, visualisation and dashboard development.

The dashboard provides insights into customer demographics, customer satisfaction, product importance, shipping preferences, shipment completion, warehouse utilisation, discounts, delivery fees and other key business performance indicators.

## Objectives

The main objectives of this project are to:

- Analyse customer demographics
- Evaluate customer satisfaction
- Analyse product importance
- Examine shipping preferences
- Evaluate shipment completion
- Analyse warehouse utilisation
- Analyse discounts and delivery fees
- Identify additional business insights

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- Microsoft PowerPoint
- GitHub

## Data Cleaning

The following data cleaning and transformation activities were carried out:

- Converted customer rating numbers into meaningful rating categories
- Converted F/M gender values into Female/Male
- Converted shipment promptness values (0/1) into On time/Delayed
- Converted discount percentages into USD values
- Created delivery fee based on product weight
- Created amount paid
- Created total amount paid

## Dashboard

The Power BI dashboard presents interactive visualisations that help users understand customer behaviour, satisfaction, shipping performance and warehouse utilisation.

## Key Insights


The analysis generated the following key insights:

- **Shipment Performance:** Out of 10,999 orders, approximately **40.3% were delivered on time**, while **59.7% were delayed**, indicating that delivery performance is an important area for operational improvement.

- **Customer Demographics:** The customer base is almost evenly distributed by gender, with **50.41% male customers and 49.59% female customers**, showing a relatively balanced customer population.

- **Customer Satisfaction:** Customer satisfaction is relatively distributed across the five rating categories, with **Poor, Fair, Average, Good and Excellent** ratings all representing a significant proportion of customers. This provides opportunities to identify factors that can improve the overall customer experience.

- **Product Importance:** Most customers classified products as having **medium (48.16%) or low (43.22%) importance**, while only **8.62%** classified products as highly important.

- **Shipping Preference:** **Ship** is the most frequently used shipment mode by a substantial margin, while **Flight and Road** account for considerably fewer orders. This suggests that shipping is the dominant method of order fulfilment.

- **Warehouse Utilisation:** Warehouse Block E recorded the highest order volume, while the remaining warehouse blocks handled comparatively lower volumes. This indicates differences in workload distribution across warehouse locations.

- **Order Value:** The dashboard recorded an **average order value of approximately 204.94**, with male customers showing a slightly higher average order value than female customers.

- **Discounts and Delivery Fees:** Higher product-importance categories were associated with higher average discounts, while delivery fees were concentrated mainly around the lower and mid-level fee categories. These patterns provide useful insight into pricing, promotional activity and delivery costs.
